Weighted-bias edge weight — how much a win is worth

weight w = 1 + x·s with the goal-difference share s = |T_A − T_B| / (10·G) — s already folds the game count away (a 2-game 20–8 and a 3-game 30–12 both sit at s = 0.6).

Reading it: the win itself always earns the base credit 1 (the dashed x = 0 line — the plain binary matrix); the extra part x·s rewards domination, fanning out to 1 + x at a full sweep. Doc example 1 (10-4, 9-10, 10-3) lands at s = 0.4.
